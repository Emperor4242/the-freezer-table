# Recipe idea photos

These photorealistic images were generated using the built-in image generation tool. They are illustrative concepts for untested recipes, not photographs of cooked or tested versions of these recipes. Each website card labels its image as an AI-generated example.

The website uses the ten `.webp` files in this folder, optimised to 960 × 640 pixels. No external image service or runtime API is required.

## Shared prompt

Use case: photorealistic-natural. Asset type: food photo for a batch-cooking recipe website. Create one photorealistic editorial photograph, landscape 3:2 composition, natural soft window light, warm neutral cream tabletop, simple off-white ceramic cookware, realistic textures and appetising home-cooked food. Camera at a high three-quarter angle, entire dish visible with a little breathing room, food fills most of frame and remains clear in a small website card. No text, labels, watermark, people, collage, illustration or 3D-render look. No beef or pork.
