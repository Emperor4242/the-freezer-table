# The Freezer Table

A small, self-contained recipe website, based on the batch-cooking dishes developed in this conversation.

## What's included

Six complete recipes:
- Lamb shepherd's pie
- Spinach and ricotta lasagne
- Chicken Parmesan cutlets with tomato pasta sauce
- Sweet potato and black bean burritos
- Chicken, broccoli and rice casserole
- Chicken pot pies

Features include searchable recipe cards, fresh/frozen/defrosted methods, ingredient scaling, ingredient tick-boxes, a selectable combined shopping list, printable views and a freezer reference guide. The default shopping list combines the burritos, casserole and pot pies.

## Open it

Double-click `index.html` to open it in a modern browser. No server or build tools are required. The interface is contained in one file (HTML, CSS, JavaScript and inline SVG illustrations). Optional Google Fonts require an internet connection; fallback fonts work offline.

The shopping list selection and ingredient tick-box states are stored in your browser, where permitted. They are not synced across devices.

## Deploy with Cloudflare Pages

This is a static HTML site. It needs no dependencies, build tools, database, API keys or environment variables.

1. In the Cloudflare dashboard, open **Workers & Pages** and choose **Create application > Pages > Import an existing Git repository** (also labelled **Connect to Git**).
2. Connect GitHub and select this repository. Cloudflare Pages supports private repositories; allow the Cloudflare GitHub integration to access this repository if it is not listed.
3. Use these settings:

   | Setting | Value |
   | --- | --- |
   | Production branch | `main` |
   | Framework preset | `None` |
   | Build command | `exit 0` |
   | Build output directory | `.` (the repository root) |
   | Root directory | Leave blank |
   | Environment variables | None |

4. Choose **Save and Deploy**. Cloudflare will provide the website's `pages.dev` address after a successful deployment.
5. To use your own domain later, open the Pages project's **Custom domains** section.

Future pushes to `main` will automatically update the connected website. The GitHub repository can remain private even when the deployed website is public.

The website uses hash links such as `#recipe/burritos`, so it does not need a redirect rule or a server-side router. Google Fonts are optional; the site has fallback fonts. Shopping selections and ticks stay in each visitor's browser and do not sync between devices or domains.

Official setup references: [Static HTML on Cloudflare Pages](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/) and [Git integration](https://developers.cloudflare.com/pages/get-started/git-integration/).

## Updating the website

To update recipes, edit the `recipes` array in the first `<script>` section of `index.html`. Each recipe defines its ingredient groups, preparation steps, cooking methods, freezer notes and tips. Recipe-specific artwork is generated by the `art()` function in the second `<script>` section. Colours and layouts are in the page's `<style>` section.

## Notes

Cooking times are estimates. Follow food-safety guidance, keep raw chicken chilled, check the centre is piping hot, and use a thermometer where appropriate. Only bake directly from frozen in oven dishes rated for freezer-to-oven use. The recipe calculations are ingredient estimates, not automatically rounded supermarket pack sizes.
